# Instrument 02+04 — one synth module

**Status:** draft spec, not locked. **If only one thing ships, ship this.** Filterbank in, traveling-wave bind, tiny readout. `<id>` = `02plus04`. Lock path: `instruments/02plus04/<version>/LOCK.md`.

**One-module decision** is on iff both `GATE_35` and `GATE_21` are closed (DESIGN.md). Echo only.

**`v0` always uses the classical bank.** If 04 is open, `v0` waits for 04’s lock. If 04 is closed, this lock states \(T\) and the margins itself.

**Import names (always versioned).** `bank_wave` is a prefix, never an import path.

| Name | Stem | Lock path |
|---|---|---|
| `bank_wave_v0` | classical Gabor + lattice (**first lock**) | `instruments/02plus04/v0/LOCK.md` |
| `bank_wave_v1` | frozen-02 + lattice (second lock, only if 02 has frozen) | `instruments/02plus04/v1/LOCK.md` |

Each version’s lock states its stem and its \(P_{\mathrm{frozen\_inherit}}\).

## Idea

A named module the warehouse can take as a **frozen stem**:

```
image → frozen bank (classical Gabor for v0; frozen 02 for v1) → wave on lattice → scar readout → bind map
```

02 (or the classical bank) supplies geometry the oscillator would otherwise have to re-encode. 04 binds without labels and without a mask. The readout is a meter, not the product.

This is a **Eurorack slot**: filter → oscillator network → VCA. Not a foundation model. Delay is **not** in this slot (that is 05).

## Spec

- End-to-end of *this module* is 04’s **bind meter** (ARI on two overlapping blobs after \(T\), overlap excluded, no mask). Never ImageNet. Never 02’s invariance bench as the module score.
- \(T\), \(M_{\mathrm{beat}}\), \(M_{\mathrm{match}}\): **copy 04’s numbers verbatim at this lock time and record 04’s lock hash**. Later 04 changes do not propagate. If 04 is labkit-`closed` at this lock time, mint them here. Do not restate a different bar. \(M_{\mathrm{beat}} \ge M_{\mathrm{match}}\).
- 02’s 1×1 mix, if 02 has frozen: **frozen** at invariance-bench values; counted as \(P_{\mathrm{frozen\_inherit}}\) (integer in this lock, own halt). **Not** against this module’s \(P_{\max}\). If 02 is not frozen, **no mix** and \(P_{\mathrm{frozen\_inherit}}=0\).
- **Total state** = channels × nodes (live). \(T_{\mathrm{store}}\): lock writes a finite integer or `inf`. Halt on \(T_{\mathrm{store}}\) only if finite.
- Classical-bank params for v0 (orientation, scale, aperture, bandwidth, quadrature on): **minted in this lock** (LOCKS.md).

## Knobs

v0: classical Gabor (this lock’s scalars) + lattice (04’s named constants, or stated here if 04 closed) + coupling + \(T\) (copied or minted) + state budget. v1: frozen-02 instead of classical Gabor. Not delay. Not estimated \(W\). Not kNN-on-features. Not a ring of oscillators.

## Meter

04’s ARI meter. Four configurations, distinguishable, criteria locked in advance:

| # | Configuration | Role |
|---|---|---|
| 1 | readout on raw input energy, no bank, no wave | null control |
| 2 | readout on wave over raw pixels, no bank | 02 contribution (04’s composing-module exemption) |
| 3 | bank + wave + readout | the module |
| 4 | bank + readout, wave off | doctrine-5 / wave contribution |

(3) must beat (1), (2) and (4) by \(M_{\mathrm{beat}}\). If (2) matches (3) within \(M_{\mathrm{match}}\), bank is not contributing — **halt**. If (4) matches (3) within \(M_{\mathrm{match}}\), the wave is decoration — **halt**. Ties are Halt. Control readout in (1) and (4) is the **same architecture and size cap** as the scar.

## Halt

- Halt: (3) does not beat (1), (2), and (4) by \(M_{\mathrm{beat}}\). (Any outcome that does not meet Stop is a halt.)
- Halt: (2) matches (3) within \(M_{\mathrm{match}}\) (bank not contributing).
- Halt: (4) matches (3) within \(M_{\mathrm{match}}\) (wave not contributing).
- Halt: any gradient from a loss outside the bind bench.
- Halt (doctrine 3): bank finetuned; mix retrained on the bind bench; \(W\) or coupling receiving gradient; any input-dependent gate on a blueprint parameter or on the scar readout; an explicit delay element or buffered state not arising from nearest-neighbour coupling.
- Halt: trained scar exceeds \(P_{\max}\); or \(P_{\mathrm{frozen\_inherit}}\) exceeds its lock integer; or live state exceeds the budget; or \(T_{\mathrm{store}}\) is finite and exceeded.
- Halt: any bench run without `instruments/02plus04/<version>/LOCK.md` carrying a recorded draft hash.
- Halt: any meter, threshold, or margin written or changed after any bench data for that bench, from any run, has been seen.

**Stop (success):** every halt not-fired, including (3) beating (1), (2) and (4) by \(M_{\mathrm{beat}}\) with the scar under \(P_{\max}\) → freeze `bank_wave_v0` (or `v1`) and stop. End-task scores are not admissible. Any outcome that does not meet Stop is a halt.

## Scar

Exactly one trainable scar: the **linear** post-wave readout, \(P_{\max}\) an integer in the lock, trained on the bind bench only.

## Build order

**First lock (`bank_wave_v0`):** classical Gabor + lattice + the four rows. If 04 is open, wait for `instruments/04/v0/LOCK.md`. Stop.

**Second lock (`bank_wave_v1`), only if 02 has frozen:** swap in frozen-02, re-run the four rows, write a **separate** lock file. Not the first lock. Peek is scoped to this bench from any run — v0’s data is visible; v1 must not change v0’s margins. It may state its own \(P_{\mathrm{frozen\_inherit}}\).

Do **not** bring 05 in until `instruments/02plus04/v0/LOCK.md` exists **and** GATE_34 is decided.
